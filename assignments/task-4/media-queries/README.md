# Task 4: Responsive Website

## Overview

Building a responsive portfolio website using media queries.

## What I'm Doing

- Creating a single-page portfolio site
- Making it responsive for desktop, tablet, and mobile
- Using media queries to adjust layout at different breakpoints

## Files

- `index.html` - Page structure
- `styles.css` - Styling with media queries

## Notes

- Breakpoints: 768px (tablet), 480px (mobile)
- Nav stacks vertically on smaller screens
- Skills cards stack on mobile
