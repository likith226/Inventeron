# Task 5: JavaScript Functions

## Overview

Learning different types of JavaScript functions and how they work.

## What I'm Doing

- Demonstrating various function types in JavaScript
- Each button triggers a different function type
- Shows output in an output box instead of alerts

## Files

- `index.html` - Page with buttons
- `styles.css` - Basic styling
- `script.js` - All function examples

## Function Types Covered

- Function Declaration
- Function Expression
- Arrow Function
- Anonymous Function
- Callback Function
