# Task 1: Registration Form

## Overview

Building a simple registration form using HTML and CSS to practice form elements and basic styling.

## What I'm Doing

- Creating a form with fields for first name, last name, email, password, confirm password, contact number, and gender
- Styling the form with CSS to make it look clean and centered
- Adding submit and reset buttons

## Files

- `index.html` - The form structure
- `styles.css` - Styling for the form

## Notes

- Using HTML5 input types for validation (`email`, `password`, `tel`)
- Form is styled with a card-like container
